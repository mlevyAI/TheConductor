# AI Director OS — Scaffold Pack

This directory and its `.claude/` sub-tree were generated by **TheConductor**'s `conductor-scaffold-ai-director-os` command. It is the Standard Pack: a minimal, opinionated set of files that wire up AI-assisted development conventions for this project.

## What was created

| File | Purpose |
|------|---------|
| `CLAUDE.md` | Project-level AI config: stack context, style rules, auth model, compact instructions |
| `.claude/current-phase.md` | Sprint/phase scope document — read before every task, update when the phase closes |
| `.claude/settings.json` | Claude Code project hooks (lint on edit, prod-env write guard, compact check on stop) |
| `.claude/rules/frontend.md` | Frontend coding standards: components, styling, RTL/LTR, accessibility |
| `.claude/rules/api.md` | API coding standards: endpoint naming, error responses, auth middleware |
| `.claude/rules/tests.md` | Testing mandate: TDD red-green-refactor, naming conventions, mock discipline |
| `.claude/prd/template.md` | PRD template for new features — copy and fill in per feature |
| `README-scaffold.md` | This file |

## How to customize

- **Edit rules:** Open any file in `.claude/rules/` and adjust the rules for your team's conventions. The AI reads these before starting domain-specific work.
- **Update the phase:** Edit `.claude/current-phase.md` whenever a sprint starts or ends. Keep it to one active phase — use git history for the record.
- **Add PRDs:** Copy `.claude/prd/template.md` to `.claude/prd/<feature-name>.md` and fill it in. Reference it from tasks or in conversation context.
- **Re-run scaffold:** Run `conductor-scaffold-ai-director-os` again with updated answers to regenerate. Existing files will be overwritten, so commit your customizations first.

## How Compact Instructions work

When a Claude Code conversation is compacted (context window pressure), the **Compact Instructions** block in `CLAUDE.md` tells the compaction algorithm what to keep and what to drop.

**Preserved:** architecture decisions, security constraints, the current sprint scope (`.claude/current-phase.md`), acceptance criteria for in-flight work, deploy commands, environment paths, and the Compact Instructions block itself.

**Discarded:** file contents already on disk (the file is the source of truth), completed debug sessions, tool output that has been acted on, and long agent transcripts whose result was already recorded.

This means the AI can work through long sessions without losing the decisions that matter, while shedding noise that would otherwise crowd out useful context.
